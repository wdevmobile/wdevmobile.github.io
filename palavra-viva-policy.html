Política de Privacidade

Palavra Viva - Liturgia Diária

Última atualização: 18 de março de 2026

1. Introdução

O aplicativo Palavra Viva - Liturgia Diária respeita a privacidade dos seus usuários e está comprometido em protegê-la. Esta Política de Privacidade descreve como as informações são tratadas ao utilizar o aplicativo.

2. Coleta de Informações

O aplicativo não coleta, armazena ou compartilha dados pessoais dos usuários.

  • Não é necessário criar conta
  • Não solicitamos nome, e-mail ou qualquer outro dado pessoal
  • Não coletamos dados sensíveis

3. Dados de Uso

O aplicativo pode, eventualmente, utilizar serviços de terceiros que podem coletar dados anônimos e agregados, como:

  • Informações de desempenho
  • Dados técnicos do dispositivo (modelo, sistema operacional)
  • Relatórios de falhas

Esses dados não identificam o usuário individualmente.

4. Uso das Informações

Como não coletamos dados pessoais, nenhuma informação é utilizada para:

  • Identificação do usuário
  • Marketing
  • Compartilhamento com terceiros

5. Compartilhamento de Dados

O aplicativo não compartilha dados pessoais, pois não realiza coleta dessas informações.

6. Armazenamento de Dados

Não armazenamos dados pessoais em servidores ou bancos de dados.

7. Segurança

Mesmo não coletando dados pessoais, adotamos boas práticas para garantir a segurança e integridade do aplicativo.

8. Links Externos

O aplicativo pode conter links para sites externos. Não somos responsáveis pelas práticas de privacidade desses sites.

9. Privacidade Infantil

O aplicativo pode ser utilizado por pessoas de todas as idades, pois não coleta informações pessoais.

10. Alterações nesta Política

Esta Política de Privacidade pode ser atualizada periodicamente. Recomendamos que o usuário revise esta página ocasionalmente.
